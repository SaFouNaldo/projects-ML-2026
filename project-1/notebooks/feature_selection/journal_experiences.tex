\section{Conventions}
\begin{itemize}
  \item Métrique de décision : \textbf{F1} (classe positive = MICHD).
  \item Prévalence train : $28\,975 / 328\,135 \approx 8{,}83\,\%$.
  \item Pipeline de référence : \textbf{base} (54 brutes $\to$ preprocess $\sim$103 cols)
        + 7 extras \texttt{NO\_DUP\_EXTRAS} $\to$ $\sim$110 colonnes
        (\texttt{pipeline.py}).
  \item Évaluation fiable (depuis oct.\ 2026) : \textbf{5-fold OOF stratifié + IRLS},
        seuil F1 sur scores OOF poolés.
  \item Bruit du F1 (bootstrap OOF) : $\sigma \approx 0{,}002$.
        On ne retient une variante que si $\Delta\mathrm{F1} \gtrsim 0{,}005$
        ($\approx 2\sigma$), sauf mention contraire.
  \item Anciennes mesures = holdout 80/20 multi-seed + GD logistic (plus bruyantes ;
        ordres de grandeur seulement).
\end{itemize}
